# Telegram-бот психологической поддержки

> Важно: бот не является медицинским сервисом и не ставит диагнозы.

## Что делает бот

- принимает текстовые и голосовые сообщения Telegram;
- распознаёт голос (Speech-to-Text через OpenAI API);
- формирует ответ по фиксированному шаблону;
- при признаках острого кризиса (самоповреждение/насилие) выдаёт безопасную рекомендацию обратиться в экстренные службы и к близкому человеку.

## Подготовка

### 1) Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather)
2. Выполните `/newbot`
3. Сохраните токен бота

### 2) Установите ffmpeg

- Ubuntu / Debian:

```bash
sudo apt update
sudo apt install -y ffmpeg
```

- macOS (Homebrew):

```bash
brew install ffmpeg
```

### 3) Установите зависимости

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 4) Настройте переменные окружения

```bash
cp .env.example .env
```

Заполните `.env`:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather
- `OPENAI_API_KEY` — API ключ OpenAI
- `OPENAI_TRANSCRIPTION_MODEL` — модель транскрибации (по умолчанию `gpt-4o-mini-transcribe`)
- `OPENAI_CHAT_MODEL` — модель анализа (по умолчанию `gpt-4o-mini`)
- `MAX_AUDIO_MB` — максимальный размер аудио
- `LOG_LEVEL` — уровень логирования (опционально)

## Запуск

```bash
python bot.py
```

Бот работает в режиме polling.

## Поддерживаемые команды и типы сообщений

- `/start`
- `/help`
- `/cancel`
- текстовые сообщения
- голосовые сообщения Telegram (`voice`, обычно OGG/Opus; при необходимости используется конвертация через ffmpeg)

Для неподдерживаемых типов файлов бот отправляет понятное сообщение.

## Ответственный режим использования

- Бот не предоставляет медицинскую диагностику.
- Не следует использовать бот для принятия срочных или рискованных решений.
- При ухудшении состояния или риске причинения вреда себе/другим необходимо немедленно обратиться в местные экстренные службы/кризисные линии и к близким.
